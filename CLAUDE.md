# CLAUDE.md

## Git

- Use [Conventional Commits](https://www.conventionalcommits.org/) (`feat:`, `fix:`, `docs:`, `chore:`, …), with a scope where it helps, e.g. `feat(fragrance-advisor): …`.
- No `Co-Authored-By` lines or any other Claude attribution in commits or PRs. Claude is not a co-author.
- Never commit directly to `main`. Work on a feature or bugfix branch named after the commit type (`feat/…`, `fix/…`, `docs/…`) and merge from there.
