# Effects decision tree

Three levels. Each level is one `AskUserQuestion` question with at most 4 options, so ask level 1, then level 2 inside the chosen branch, then level 3. Phrase the options in the user's language and in everyday words (the labels below in quotes are suggestions). Use the descriptions to explain the subtle differences, since that's what makes the choice meaningful.

If the user picks two directions at level 1, run level 2 for the leading one and take only its level-2 node from the second (skip its level 3).

After the leaf, ask the **arc question** (see the end of this file): how the scent should change on the skin.

Each leaf gives:
- **Pyramid**: suggested top / heart / base notes (Fragrantica names; confirm with autocomplete).
- **Families**: the scent families to score in [scent-profile-chart.md](scent-profile-chart.md), main one first.
- **Sillage**: how far the scent should project: skin (arm's length), moderate (a room's corner), strong (fills a room / leaves a trail).
- **Avoid**: notes that work against this effect.

Setting rules still win: if the leaf says "strong" but they work in close contact, pick the leaf's notes and lower the sillage (lighter concentration, fewer sprays, EDT over extrait).

## Arc: how the scent changes on the skin

Ask after the leaf. The leaves describe a state; this describes the journey from the first spray to the dry-down hours later.

| Option | Description | How to build the pyramid |
|---|---|---|
| **Linear** | Smells about the same all day | Use the leaf's pyramid as it is |
| **Fresh → warm** | Bright opening, cozy finish | Top and heart from the leaf (or a C1 leaf), base from a C3 leaf |
| **Innocent → seductive** | Clean, white-floral start; dark, sensual dry-down | Top: Neroli, Bergamot; heart: Orange Blossom, Jasmine (A2a/C2a); base from A1c or A4b (Incense, Patchouli, Leather, Labdanum, Amber) |
| **Bold → soft** | Loud start, ends as a skin scent | Top and heart from the leaf, base from C2c (Musk, Ambrette (Musk Mallow), Cashmeran) |

The arc only reshapes the levels; the families still come from the leaf. In the profile score, give the arc's base families the same weight as the leaf's.
