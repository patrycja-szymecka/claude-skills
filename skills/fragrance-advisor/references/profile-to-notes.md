# Notes reference

Note names follow Fragrantica's spelling as far as known. Always confirm a name with the ingredients-search autocomplete. If it doesn't appear, use the closest note from the same family (see "Similar notes" below) rather than guessing a spelling.

## Translating vague dislikes

| The user says | Exclude / lower |
|---|---|
| "Too sweet", "sickly", "sticky" | Exclude the sugary notes (Caramel, Praline, Cotton Candy, Marshmallow, Sugar, Honey). Halve Gourmand rather than zeroing it if their liked perfumes have a vanilla or tonka base; zero it only if they reject sweetness entirely |
| "Old lady", "grandma" | Powdery family; exclude Aldehydes, Powdery Notes, Violet; lower Iris |
| "Headache", "too strong" | Lower sillage; exclude Tuberose, Agarwood (Oud), Patchouli; prefer EDT |
| "Smells like a man / like a woman" | Gender filter, and the families they mean (often Leather/Smoky or Floral) |
| "Cheap", "synthetic", "chemical" | Lower Ambroxan, Calone, Iso E Super-heavy sweet blends; prefer natural-leaning niche |
| "Soapy" | Exclude Aldehydes, White Musk, Lavender-heavy |
| "Smoky", "ashtray" | Leather/Smoky family; exclude Birch Tar, Smoke, Tobacco |
| "Like a cleaning product" | Exclude Calone, Lemon-only openings, Pine |

## By age (soft guidance, tie-breaker only)

- **Under 25**: brighter, fruitier, sweeter, higher-projection scents usually go over well.
- **25–40**: balanced; one fresh and one warm option.
- **40–55**: refined materials (Iris, Leather, Sandalwood, Rose); fine to go niche.
- **55+**: classic structures such as chypre (Bergamot + Oakmoss + Patchouli) and fougère (Lavender + Coumarin + Oakmoss), or plush musks. Don't steer away from modern scents if they like them.

## Gender filter

Fragrantica labels perfumes "for women", "for men" or "for women and men" (unisex). Include unisex unless the user said no.
