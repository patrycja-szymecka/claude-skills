# Price tiers

The interview doesn't ask about budget. Instead, every mode in the report shows one budget, one designer and one niche perfume, so the user sees the best match at every price.

## Tiers

Prices are for 100 ml (scale smaller bottles up). Use the user's currency and convert these bounds roughly.

| Tier | EUR / USD per 100 ml | What it is |
|---|---|---|
| **Budget** | up to ~45 | Mass-market, high-street and Middle-Eastern houses; also good "inspired by" scents |
| **Designer** | ~45–160 | Fashion and beauty houses sold in every perfumery |
| **Niche** | over ~160 | Independent and luxury perfume houses |

**Assign the tier by the price you actually found.** If you couldn't check the price, use the brand lists below and write "price not checked". Prices vary by shop and concentration (EDT is usually cheaper than EDP), so a perfume near a boundary goes into the tier its typical 100 ml EDP/EDT price falls into; say so if it's borderline.

## Picking the eighteen

The report has three modes (day, work, evening). In each mode, each tier (budget, designer, niche) gets **two perfumes: one exact match** (pyramid matches level by level, search stage 1) **and one similar match** (same mood, different build, stages 2–3). Eighteen in total, no perfume twice. The page shows them with a "Dokładne / Podobne" switch, three at a time.

1. Search with each mode's anchors ([scent-profile-chart.md](scent-profile-chart.md)); a candidate can qualify for more than one mode, but place it where it fits best.
2. Within a mode and tier, take the best fit: stage 1 before stage 2 before stage 3, then how many of the mode's top families it matches, then Fragrantica rating and review count.
3. Check sillage against the mode: a loud budget Middle-Eastern scent can still go to work if you say so in the wearing note ("one spray") and the mismatch line.
4. In the budget tier, an "inspired by" perfume is fine if you say what it's inspired by and confirm its notes separately.
5. **Display order**: always budget, designer, niche on both sides of the switch.
6. If a tier has no honest exact (or similar) match after all four search stages, leave that slot empty rather than filling it with a weak pick; don't explain it in the report.
7. Prefer perfumes that are still sold (a current shop listing is the best proof).
